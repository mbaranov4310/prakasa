```samhita
कर्म ब्रह्मोद्भवं विद्धि ब्रह्माक्षरसमुद्भवम् ।
तस्मात्सर्वगतं ब्रह्म नित्यं यज्ञे प्रतिष्ठितम् ॥
```

```translation
Know action as arising from the Veda, and the Veda as arising from the Imperishable. Therefore the Veda, which reaches everything, is forever set firm in sacrifice.
```

```phrase
Know action as arising from the Veda, and the Veda as arising from the Imperishable.
---
Therefore the Veda, which reaches everything, is forever set firm in sacrifice.
```
