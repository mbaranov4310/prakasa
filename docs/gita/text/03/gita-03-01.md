```samhita
अर्जुन उवाच
ज्यायसी चेत्कर्मणस्ते मता बुद्धिर्जनार्दन ।
तत्किं कर्मणि घोरे मां नियोजयसि केशव ॥
```

```translation
Arjuna said: If you hold knowledge to be better than action, O Janardana, why then do you set me to this terrible action, O Keshava?
```

```phrase
Arjuna said:
```
