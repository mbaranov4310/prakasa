```samhita
अपरेयमितस्त्वन्यां प्रकृतिं विद्धि मे पराम् ।
जीवभूतां महाबाहो ययेदं धार्यते जगत् ॥
```

```translation
This is the lower nature. Other than it, know my higher nature, which has become the life-principle, O mighty-armed, the nature by which this world is held up.
```

```phrase
This is the lower. Other than it, know my higher nature.
---
It has become the life-principle, O mighty-armed, by which this world is held up.
```
