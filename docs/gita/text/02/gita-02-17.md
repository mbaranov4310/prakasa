```samhita
अविनाशि तु तद्विद्धि येन सर्वमिदं ततम् ।
विनाशमव्ययस्यास्य न कश्चित्कर्तुमर्हति ॥
```

```translation
Know that, by contrast, to be what does not perish: that by which all this world is pervaded. No one can bring this unchanging one to an end.
```

```phrase
Know that, by contrast, to be what does not perish, that by which all this is pervaded.
---
No one is able to destroy this unchanging one.
```
