judgment: obvious

voice: parasmaipada

number: singular

## atha
ids: gita-03-36-w3
kind: indeclinable
judgment: obvious
meaning: now

## kena
ids: gita-03-36-w4
kind: pronoun
judgment: obvious
stem: kim
gender: masculine
case: instrumental
number: singular
note: Śaṅkara reads it as the cause, hetu-bhūtena. It is what the man is driven by.
meaning: by what

## prayuktaḥ
ids: gita-03-36-w5
kind: participle
judgment: obvious
root: yuj
prefix: pra
participle: past
gender: masculine
case: nominative
number: singular
note: It agrees with pūruṣaḥ, and with ayam, the same man. Written prayukto 'yam; the visarga becomes o, and the a of ayam is dropped.
meaning: driven

## ayam
ids: gita-03-36-w6
kind: pronoun
judgment: obvious
stem: idam
gender: masculine
case: nominative
number: singular
note: The a is dropped after prayuktaḥ, so only yam shows.
meaning: this

## pāpam
ids: gita-03-36-w7
kind: noun
judgment: obvious
stem: pāpa
gender: neuter
case: accusative
number: singular
note: The neuter -am is nominative or accusative. It is what he does, so it is accusative. Śaṅkara supplies karma, an evil act. Written pāpaṃ before carati.
meaning: evil

number: singular

## anicchan
ids: gita-03-36-w10
kind: participle
judgment: obvious
root: iṣ
participle: present
gender: masculine
case: nominative
number: singular
note: Negated present participle of iṣ. It agrees with pūruṣaḥ. Written anicchann before api; the a of api joins the n.
meaning: not wishing

## api
ids: gita-03-36-w11
kind: indeclinable
judgment: obvious
note: Joined to anicchan, so only pi shows.
meaning: even

## vārṣṇeya
ids: gita-03-36-w12
kind: noun
judgment: obvious
stem: vārṣṇeya
gender: masculine
case: vocative
number: singular
note: Śaṅkara glosses vṛṣṇi-kula-prasūta, born in the Vṛṣṇi line.
meaning: O descendant of Vrishni

## balāt
ids: gita-03-36-w13
kind: noun
judgment: obvious
stem: bala
gender: neuter
case: ablative
number: singular
note: Ablative of cause. Written balād iva; t becomes d, and the i of iva is written on that d, so iva shows as va.
meaning: by force

## iva
ids: gita-03-36-w14
kind: indeclinable
judgment: obvious
note: The i joins balāt, so only va shows.
meaning: as if
