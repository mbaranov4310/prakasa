# gita-03-15

## karma
ids: gita-03-15-w1
kind: noun
judgment: obvious
stem: karman
gender: neuter
case: accusative
number: singular
root: kṛ
note: The neuter form karma is nominative or accusative. It is what you should know, so it is accusative.
meaning: action

## brahma-udbhavam
ids: gita-03-15-w2
kind: adjective
judgment: obvious
stem: brahma-udbhava
gender: neuter
case: accusative
number: singular
compound: bahuvrīhi
note: “Whose origin (udbhava, from ud-bhū) is the Veda (brahma).” It agrees with karma. The neuter -am is nominative or accusative. It describes action, so it is accusative. Written brahmodbhavam: a and u join into o.
meaning: arising from the Veda

## viddhi
ids: gita-03-15-w3
kind: verb
judgment: obvious
root: vid
class: ad
tense: command
voice: parasmaipada
person: 2nd
number: singular
note: Imperative of vid, class 2. The subject “you” is not spoken.
meaning: know

## brahma
ids: gita-03-15-w4
kind: noun
judgment: obvious
stem: brahman
gender: neuter
case: accusative
number: singular
note: The neuter form brahma is nominative or accusative. It is the second thing to know, the Veda, so it is accusative. Written brahmā before akṣara: the two a’s join into ā.
meaning: the Veda

## akṣara-samudbhavam
ids: gita-03-15-w5
kind: adjective
judgment: obvious
stem: akṣara-samudbhava
gender: neuter
case: accusative
number: singular
compound: bahuvrīhi
note: “Whose arising (samudbhava, from sam-ud-bhū) is the Imperishable (akṣara).” It agrees with brahma, the Veda. The neuter -am is nominative or accusative. It describes that Veda, so it is accusative. The initial a is in the ā of brahmā.
meaning: arisen from the Imperishable

## tasmāt
ids: gita-03-15-w6
kind: pronoun
judgment: obvious
stem: tad
gender: neuter
case: ablative
number: singular
note: The ablative singular is the same in masculine and neuter. It points back to what was just said, so it is neuter. “From that” is “therefore.”
meaning: therefore

## sarva-gatam
ids: gita-03-15-w7
kind: adjective
judgment: obvious
stem: sarva-gata
gender: neuter
case: nominative
number: singular
root: gam
compound: tatpuruṣa
note: gata is the past participle of gam. Reaching everything. The neuter -am is nominative or accusative. It agrees with the Veda that is set firm, so it is nominative. Written sarva-gataṃ before brahma.
meaning: reaching everything (it lights up every object)

## brahma
ids: gita-03-15-w8
kind: noun
judgment: obvious
stem: brahman
gender: neuter
case: nominative
number: singular
note: The neuter form brahma is nominative or accusative. It is what is set firm in sacrifice, the Veda, so it is nominative.
meaning: the Veda

## nityam
ids: gita-03-15-w9
kind: indeclinable
judgment: obvious
note: The neuter accusative singular of nitya. It could agree with brahma. It says for how long the Veda is set firm, so it is an adverb. Written nityaṃ before yajñe.
meaning: forever

## yajñe
ids: gita-03-15-w10
kind: noun
judgment: obvious
stem: yajña
gender: masculine
case: locative
number: singular
root: yaj
meaning: in sacrifice

## pratiṣṭhitam
ids: gita-03-15-w11
kind: participle
judgment: obvious
root: sthā
prefix: prati
participle: past
gender: neuter
case: nominative
number: singular
note: Past participle of sthā with prati, passive in sense, “set firm.” It agrees with brahma. The neuter -am is nominative or accusative. It is what is said of the Veda, so it is nominative. There is no finite verb.
meaning: set firm
