# gita-06-25

## śanaiḥ
ids: gita-06-25-w1
kind: indeclinable
judgment: obvious
note: The instrumental plural of śana, used as an adverb.
meaning: little by little

## śanaiḥ
ids: gita-06-25-w2
kind: indeclinable
judgment: obvious
note: The same adverb again. Written śanair before the u of uparamet.
meaning: little by little (not all at once)

## uparamet
ids: gita-06-25-w3
kind: verb
judgment: obvious
root: ram
prefix: upa
tense: potential
voice: parasmaipada
person: 3rd
number: singular
note: The initial u is written with the preceding śanaiḥ. The final t is written d before buddhyā.
meaning: one should draw back

## buddhyā
ids: gita-06-25-w4
kind: noun
judgment: obvious
stem: buddhi
gender: feminine
case: instrumental
number: singular
root: budh
meaning: by the intellect

## dhṛti-gṛhītayā
ids: gita-06-25-w5
kind: adjective
judgment: obvious
stem: dhṛti-gṛhīta
gender: feminine
case: instrumental
number: singular
root: grah
compound: tatpuruṣa
note: gṛhīta is the past participle of grah. Instrumental tatpuruṣa: held by firmness.
meaning: held by firmness

## ātma-saṃstham
ids: gita-06-25-w6
kind: adjective
judgment: obvious
stem: ātma-saṃstha
gender: neuter
case: accusative
number: singular
root: sthā
prefix: sam
compound: tatpuruṣa
note: saṃstha is “set, standing” from sthā with sam. Locative tatpuruṣa: set in the self. Written ātmasaṃsthaṃ before manaḥ. The neuter -am is nominative or accusative. It is the state one makes the mind into, so it is accusative.
meaning: set firm in the self (sure that the self is all, and nothing else is)

## manaḥ
ids: gita-06-25-w7
kind: noun
judgment: obvious
stem: manas
gender: neuter
case: accusative
number: singular
root: man
note: The neuter ending is nominative or accusative. It is what one sets firm in the self, so it is accusative.
meaning: the mind

## kṛtvā

## na
ids: gita-06-25-w9

## kiṃcit
ids: gita-06-25-w10
kind: pronoun
judgment: obvious
stem: kim
gender: neuter
case: accusative
number: singular
note: kim with the particle cit. Written kiṃcid before api, and that a is dropped. The neuter form is nominative or accusative. It is what one should not think of, so it is accusative.
meaning: anything

## api
ids: gita-06-25-w11
kind: indeclinable
judgment: obvious
note: The initial a is dropped after kiṃcid.
meaning: at all
