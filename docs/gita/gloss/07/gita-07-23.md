# gita-07-23

## anta-vat
ids: gita-07-23-w1
kind: adjective
judgment: obvious
stem: anta-vat
gender: neuter
case: nominative
number: singular
note: anta with the suffix -vat, “having an end.” Neuter, with the fruit. This ending is nominative or accusative. It is what the fruit comes to be, so it is nominative. Joined to tu.
meaning: coming to an end (perishing)

## tu
ids: gita-07-23-w2
kind: indeclinable
judgment: obvious
note: Joined after anta-vat.
meaning: but

## phalam
ids: gita-07-23-w3
kind: noun
judgment: obvious
stem: phala
gender: neuter
case: nominative
number: singular
root: phal
note: The neuter -am is nominative or accusative. It is what comes to be, so it is nominative. Written phalaṃ.
meaning: the fruit
