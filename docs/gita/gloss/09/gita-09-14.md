# gita-09-14

## satatam
ids: gita-09-14-w1
kind: indeclinable
judgment: obvious
note: The neuter accusative singular of satata, used as an adverb. It says that the praising is constant.
meaning: always

## kīrtayantaḥ
ids: gita-09-14-w2
kind: participle
judgment: obvious
root: kīrt
participle: present
gender: masculine
case: nominative
number: plural
note: It agrees with nitya-yuktāḥ. Written kīrtayanto before mām.
meaning: praising

## mām
ids: gita-09-14-w3
kind: pronoun
judgment: obvious
stem: asmad
case: accusative
number: singular
note: asmad has no gender. Written māṃ before yatantaḥ.
meaning: me

## yatantaḥ
ids: gita-09-14-w4
kind: participle
judgment: obvious
root: yat
participle: present
gender: masculine
case: nominative
number: plural
note: It agrees with nitya-yuktāḥ. Written yatantaś before ca.
meaning: striving (by calm, restraint, kindness, and non-harm)

## ca
ids: gita-09-14-w5, gita-09-14-w8

meaning: and
