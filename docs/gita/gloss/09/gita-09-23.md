## ye
ids: gita-09-23-w1
kind: pronoun
judgment: obvious
stem: yad
gender: masculine
case: nominative
number: plural
note: Written ye before api, and the a of api is dropped.
meaning: those who

case: nominative
number: plural
root: bhaj
