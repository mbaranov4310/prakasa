# gita-09-15

## jñāna-yajñena
ids: gita-09-15-w1
kind: noun
judgment: obvious
stem: jñāna-yajña
gender: masculine
case: instrumental
number: singular
root: yaj
compound: karmadhāraya
note: Knowledge (jñāna, from jñā) itself is the sacrifice (yajña, from yaj).
meaning: by the sacrifice that is knowledge

## ca
ids: gita-09-15-w2
kind: indeclinable
judgment: obvious
note: Written cā before api.
meaning: and

## api
ids: gita-09-15-w3
kind: indeclinable
judgment: obvious

meaning: also
