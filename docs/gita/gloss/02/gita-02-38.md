# gita-02-38

## sukha-duḥkhe
ids: gita-02-38-w1
kind: noun
judgment: obvious
stem: sukha-duḥkha
gender: neuter
case: accusative
number: dual
compound: dvandva
note: “Pleasure and pain.” The dual -e is nominative or accusative. It is what is made the same, so it is accusative.
meaning: pleasure and pain

## same
ids: gita-02-38-w2
kind: adjective
judgment: obvious
stem: sama
gender: neuter
case: accusative
number: dual
note: The dual same is nominative or accusative. It agrees with sukha-duḥkhe, so it is accusative. The two masculine pairs would take samau; this form is neuter and agrees with sukha-duḥkhe.
meaning: the same (and so without attraction or aversion)

## kṛtvā
ids: gita-02-38-w3
kind: indeclinable
judgment: obvious
root: kṛ
note: An absolutive in -tvā. The same making is understood again with the two pairs that follow.
meaning: having made

## lābha-alābhau
ids: gita-02-38-w4
kind: noun
judgment: obvious
stem: lābha-alābha
gender: masculine
case: accusative
number: dual
root: labh
compound: dvandva
note: “Gain and its absence.” The dual -au is nominative or accusative. It is an object of kṛtvā, so it is accusative. lābha is from labh.
meaning: gain and loss

## jaya-ajayau
ids: gita-02-38-w5
kind: noun
judgment: obvious
stem: jaya-ajaya
gender: masculine
case: accusative
number: dual
root: ji
compound: dvandva
note: “Victory and its absence.” The dual -au is nominative or accusative. It is an object of kṛtvā, so it is accusative. jaya is from ji.
meaning: victory and defeat

## yujyasva
ids: gita-02-38-w8
kind: verb
judgment: obvious
root: yuj
class: div
tense: command
voice: ātmanepada
person: 2nd
number: singular
note: Middle command of yuj, “set yourself.” The present yujyate is class 4. Class 7 would be yuṅkṣva. The subject “you” is not spoken.
meaning: set yourself

## na
ids: gita-02-38-w9
kind: indeclinable
judgment: obvious
note: Written nai before vam: a joins the e of evam.
meaning: not

## evam
ids: gita-02-38-w10
kind: indeclinable
judgment: obvious
note: Its e joins na, so the slice is vam.
meaning: in this way

## pāpam
ids: gita-02-38-w11
kind: noun
judgment: obvious
stem: pāpa
gender: neuter
case: accusative
number: singular
note: The neuter -am is what you will incur, so it is accusative. Written pāpam before avāpsyasi.
meaning: evil

## avāpsyasi
ids: gita-02-38-w12
kind: verb
judgment: obvious
root: āp
prefix: ava
class: su
tense: simple future
voice: parasmaipada
person: 2nd
number: singular
note: Future of āp with ava. The present is āpnoti, class 5. The future stem does not show the class. The subject “you” is not spoken. Its initial a joins pāpam.
meaning: will you incur
