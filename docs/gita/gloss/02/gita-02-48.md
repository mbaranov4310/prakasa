# gita-02-48

## yoga-sthaḥ
ids: gita-02-48-w1
kind: adjective
judgment: obvious
stem: yoga-stha
gender: masculine
case: nominative
number: singular
root: sthā
compound: tatpuruṣa
note: “Standing (stha, from sthā) in yoga.” It agrees with the unstated “you” of kuru.
meaning: standing in yoga
