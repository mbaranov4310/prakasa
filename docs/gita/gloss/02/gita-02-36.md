# gita-02-36

## avācya-vādān
ids: gita-02-36-w1
kind: noun
judgment: obvious
stem: avācya-vāda
gender: masculine
case: accusative
number: plural
root: vad
compound: karmadhāraya
note: avācya is a- with vācya, the potential participle in -ya of vac, “not to be said.” vāda, from vad, is “a saying.” Written -vādāṃś before ca.
meaning: things that should not be said

meaning: enemies
