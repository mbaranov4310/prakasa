# gita-02-62

## dhyāyataḥ
ids: gita-02-62-w1
kind: participle
judgment: obvious
root: dhyai
participle: present
gender: masculine
case: genitive
number: singular
note: Present participle of dhyai. The ending -ataḥ is genitive or ablative. It agrees with puṃsaḥ, so it is genitive. Written dhyāyato before viṣayān.
meaning: of one who dwells on them

ids: gita-02-62-w5

stem: tad

case: locative
number: plural

meaning: to those
