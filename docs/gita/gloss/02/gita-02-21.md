# gita-02-21

## veda
ids: gita-02-21-w1
kind: verb
judgment: obvious
root: vid
class: ad
tense: distant past

number: singular
note: Perfect of vid, class 2, used as a present, “knows.” It joins avināśinam.

number: singular
