# gita-04-16

## kim
ids: gita-04-16-w1, gita-04-16-w3
kind: pronoun
judgment: obvious
stem: kim
gender: neuter
case: nominative
number: singular
note: The neuter kim is nominative or accusative. It is the predicate of the question, so it is nominative. The first is written kiṃ before karma. The second joins akarma as kima.
meaning: what

## karma
ids: gita-04-16-w2
kind: noun
judgment: obvious
stem: karman
gender: neuter
case: nominative
number: singular
root: kṛ
note: The form karma is nominative or accusative. It is what the question is about, so it is nominative.
meaning: action

## akarma
ids: gita-04-16-w4
kind: noun
judgment: obvious
stem: a-karman
gender: neuter
case: nominative
number: singular
root: kṛ
compound: tatpuruṣa
note: Negative compound, non-action. The form akarma is nominative or accusative. It is what the second question is about, so it is nominative. Written karme before iti.
meaning: non-action

## iti
ids: gita-04-16-w5
kind: indeclinable
judgment: obvious
note: The i joins akarma, and the line reads akarmeti.
meaning: thus

## kavayaḥ
ids: gita-04-16-w6
kind: noun
judgment: obvious
stem: kavi
gender: masculine
case: nominative
number: plural
note: Written kavayo before api, and the a of api is dropped.
meaning: the wise

## api
ids: gita-04-16-w7
kind: indeclinable
judgment: obvious
note: Written pya before atra.
meaning: even

## atra
ids: gita-04-16-w8
kind: indeclinable
judgment: obvious
note: Joined with api, the line reads apyatra.
meaning: here (about action and the rest)

## mohitāḥ
ids: gita-04-16-w9
kind: participle

root: muh
participle: past
gender: masculine
case: nominative
number: plural

## tat
ids: gita-04-16-w10
kind: pronoun
judgment: obvious
stem: tad
gender: neuter
case: accusative
number: singular
note: The form tat is nominative or accusative. It agrees with the action to be declared, so it is accusative. Joined with te as tat te.
meaning: that

## te
ids: gita-04-16-w11
kind: pronoun
judgment: obvious
stem: yuṣmad
case: dative
number: singular
note: yuṣmad has no gender. The form te is dative or genitive. It is the person the declaration is for, so it is dative.
meaning: to you

## karma
ids: gita-04-16-w12
kind: noun
judgment: obvious
stem: karman
gender: neuter
case: accusative
number: singular
root: kṛ
note: The form karma is nominative or accusative. It is what is declared, so it is accusative.
meaning: action (and non-action with it)

number: singular
