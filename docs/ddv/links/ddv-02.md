# ddv-02

## subject
from: ddv-02-w12
to: ddv-02-w13
judgment: obvious
note: locanam is nominative or accusative. paśyet is singular and rūpāṇi is plural, so the eye is who sees.

## object
from: ddv-02-w12
to: ddv-02-w11
judgment: obvious
note: rūpāṇi is nominative or accusative. It is plural and cannot be the subject of the singular paśyet, so the forms are what is seen.

## describes
from: ddv-02-w10
to: ddv-02-w11
judgment: obvious
note: nānāvidhāni matches rūpāṇi in case, whether that case is nominative or accusative.
