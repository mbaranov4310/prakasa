## complement
from: bn-purusaya
to: bn-namah
judgment: obvious
note: Dative with namaḥ. There is no finite verb, so namaḥ is the head. The Puruṣa is who the salutation is to.

## describes
from: bn-namne
to: bn-purusaya
judgment: obvious
note: nāmne is dative singular and agrees with puruṣāya, whatever the number in the stored meaning.

## describes
from: bn-sasvate
to: bn-purusaya
judgment: unsure
why: śāśvate agrees with puruṣāya only if it is a dative from śāśvat, and from śāśvata it is a locative.

## complement
