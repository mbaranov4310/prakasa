# pranayama

## describes
from: p-tat
to: p-bhargo
judgment: obvious
note: tat is used as an adjective here. tat and bhargaḥ are both neuter, nominative or accusative singular.

## complement
from: p-savitur
to: p-bhargo
judgment: obvious
note: savituḥ is ablative or genitive. With bhargaḥ it is the genitive. The radiance is what Savitṛ possesses.

## describes
from: p-varenyam
to: p-bhargo
judgment: obvious
note: vareṇyam matches the neuter bhargaḥ, whether that case is nominative or accusative.

## object
from: p-dhimahi
to: p-bhargo
judgment: obvious
note: bhargaḥ is nominative or accusative. dhīmahi needs an object.

## complement
from: p-devasya
judgment: unsure
why: devasya can be the god whose radiance it is, with bhargaḥ, or agree with savituḥ as “the divine Savitṛ.”

## subject
from: p-pracodayat
to: p-yo
judgment: obvious

## object
from: p-pracodayat
to: p-dhiyo
judgment: obvious
note: dhiyaḥ can be several cases. naḥ is “our,” so the intellect is what he impels.

## complement
from: p-nah
to: p-dhiyo
judgment: obvious
note: naḥ is accusative, dative, or genitive. The stored sense “our” is the genitive. The intellect is what we possess.

## same
from: p-yo
to: p-savitur
judgment: obvious
note: yaḥ is masculine singular. Savitṛ is the one who impels.
