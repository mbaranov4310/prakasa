# mudra-pradarsanam

## describes
from: mp-caturvimsati
to: mp-mudra-1
judgment: unsure
why: caturviṃśati is a bare compound front with no case, and a numeral noun is not a clean adjective of mudrāḥ.

## describes
from: mp-supratisthitah
to: mp-mudra-1
judgment: obvious
note: supratiṣṭhitāḥ matches mudrāḥ in case, whether that case is nominative or accusative.

## complement
from: mp-gayatryam
to: mp-supratisthitah
judgment: obvious
note: Locative. Gāyatrī is where the mudrās are established.

## object
from: mp-janati
to: mp-mudra-2
judgment: obvious
note: mudrāḥ is nominative or accusative. jānāti needs an object, and the mudrās are what is not known.

## object
from: mp-prerayet

## complement

## describes

## complement
