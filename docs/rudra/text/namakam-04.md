## 4.5.4.1

```samhita
नम आव्याधिनीभ्यो विविद्ध्यन्तीभ्यश्च वो नमो नम उगणाभ्यस्तृꣳहतीभ्यश्च वो नमो नमो गृत्सेभ्यो गृत्सपतिभ्यश्च वो नमो नमो व्रातेभ्यो व्रातपतिभ्यश्च वो नमो नमो गणेभ्यो गणपतिभ्यश्च वो नमो नमो विरूपेभ्यो विश्वरूपेभ्यश्च वो नमो नमो महद्भ्यः क्षुल्लकेभ्यश्च वो नमो नमो रथिभ्योऽरथेभ्यश्च वो नमो नमो रथेभ्यो
```

## 4.5.4.2

```samhita
रथपतिभ्यश्च वो नमो नमः सेनाभ्यः सेनानिभ्यश्च वो नमो नमः क्षत्तृभ्यः संग्रहीतृभ्यश्च वो नमो नमस्तक्षभ्यो रथकारेभ्यश्च वो नमो नमः कुलालेभ्यः कर्मारेभ्यश्च वो नमो नमः पुञ्जिष्टेभ्यो निषादेभ्यश्च वो नमो नम इषुकृद्भ्यो धन्वकृद्भ्यश्च वो नमो नमो मृगयुभ्यः श्वनिभ्यश्च वो नमो नमः श्वभ्यः श्वपतिभ्यश्च वो नमः ॥
```
